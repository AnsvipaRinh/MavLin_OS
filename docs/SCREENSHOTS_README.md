## Screens Explanation

**boot-menu.png** (kept) — This is the verified boot menu screenshot from QEMU, properly tracked and documented in README.md. This frame meets the size (<500KB) and quality requirements.

**raw-frame-*.png files** (diagnostic captures) — These are diagnostic capture files from QEMU runs, all approximately 3MB each, exceeding the 500KB size constraint. They are maintained for diagnostic traceability but are not referenced in the documentation as they do not meet the size requirements for the README gallery.

The boot-menu.png is the official, production-ready screenshot that represents the system. All other QEMU captures remain in the repository as diagnostic artifacts for troubleshooting and testing.

**Reasoning:** Diagnostic captures are necessary for troubleshooting and testing but are not suitable for documentation gallery due to their size. The repository maintains a clear separation between production-ready documentation assets and diagnostic tools.
